# Web Development & Designing Internship (Oasis Infobyte)
## Level 1 — Task 2: Personal Portfolio Website

A modern, responsive, and dynamic personal portfolio website engineered with semantic HTML5, modular CSS3, and vanilla JavaScript. Designed to present academic credentials, technical skills, featured engineering projects, and verified certifications.

## 🌟 Key Features

1. **Light / Dark Mode Toggle:**
   - Seamless instant theme switching with smooth CSS variable transitions and persistent state.

2. **Hero Section with Typewriter Animation:**
   - Dynamic JavaScript typewriter effect highlighting core aspirations (`Aspiring Web Developer`, `Tech Enthusiast`, `Problem Solver`).
   - Profile showcase with responsive card styling.

3. **Embedded Resume & Direct Download:**
   - Detailed academic summary, core strengths, and a direct link to view/download the original `resume.pdf`.

4. **Technical Competencies Grid:**
   - Categorized technology cards covering Frontend (HTML5, CSS3, JS), Programming (Python, Java, C++), Databases (SQL), and Tools (Git, GitHub, VS Code).

5. **Featured Engineering Projects:**
   - **Intelligent Distributed Log Analysis & Root Cause Detection:** Log parsing pipeline using Drain3 and Isolation Forest anomaly detection.
   - **SyncBoard:** Real-time collaborative code editor with Flask-SocketIO and CodeMirror.
   - **IoT-Based Home Automation System:** Remote appliance control using ESP32/ESP8266 and relay modules (Published Research).

6. **Credentials & Certifications Showcase:**
   - Direct verification links (`.pdf`) for all official achievements:
     - Research Paper Publication (IJARSCT International Journal - Impact Factor 7.53)
     - NPTEL Elite Certification in Cloud Computing (IIT Kharagpur)
     - NPTEL Elite Certification in Introduction to Machine Learning (IIT Kharagpur)
     - DSA in C++ Virtual Internship (AICTE - EduSkills)
     - AI-ML Virtual Internship (Google for Developers & AICTE)
     - Java Full Stack Developer (EduSkills Academy)
     - Gemini Certified Student (Google for Education)
     - AWS Academy Graduate - Generative AI Foundations
     - Build with AI Agent Builder Camp (GeeksforGeeks & Google)

7. **Clean Contact Interface:**
   - Direct access channels via Email, Phone, LinkedIn, and GitHub.
