# Web Development - Level 1 - Task 1: Landing Page

A responsive, modern static landing page built with semantic HTML5 and CSS3 for **ApexCloud**, a developer platform.

## Features Included
- **Sticky Navigation Bar:** Accessible navigation with smooth jump links.
- **Hero Section:** Actionable headline, subtext, and call-to-action buttons.
- **Features & About Sections:** CSS Grid/Flexbox layouts detailing key highlights and business metrics.
- **Testimonials Section:** Social proof cards with consistent visual styling.
- **Footer:** Informational links, social links, and copyright text.
- **Fully Responsive:** Adapts seamlessly across desktop, tablet, and mobile screens.

## Tech Stack
- **HTML5:** Semantic document structuring.
- **CSS3:** Flexbox, CSS Grid, custom properties (CSS variables), and media queries.
