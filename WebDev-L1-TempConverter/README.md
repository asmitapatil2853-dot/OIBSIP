# Web Development & Designing Internship (Oasis Infobyte)
## Level 1 — Task 3: Temperature Converter Website

A modern, responsive, and dynamic Temperature Converter web application built using semantic HTML5, modern CSS3 (glassmorphism & dark tech theme), and vanilla JavaScript. The application converts temperatures seamlessly between Celsius, Fahrenheit, and Kelvin with formula explanations.

---

- **Live Website:** [View Temperature Converter](https://asmitapatil2853-dot.github.io/OIBSIP/WebDev-L1-TempConverter/)
- **GitHub Repository:** [OIBSIP Repository](https://github.com/asmitapatil2853-dot/OIBSIP)

---

## 🌟 Key Features

1. **Multi-Unit Conversion:**
   - Supports bi-directional conversions across Celsius (°C), Fahrenheit (°F), and Kelvin (K).

2. **One-Click Unit Swapping:**
   - Dedicated swap button (`⇄`) to instantly switch "From" and "To" units and recalculate on the fly.

3. **Formula Transparency:**
   - Displays the exact mathematical formula used for the conversion along with the calculated result.

4. **Input Validation & Keyboard Support:**
   - Handles numeric edge cases gracefully and supports triggering conversions directly via the `Enter` key.

5. **Modern Tech UI:**
   - Styled with dark glowing glassmorphism, responsive input controls, and smooth fade-in animations.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup and accessible form controls
- **CSS3:** Flexbox, CSS variables, glassmorphism blur effects, and responsive media queries
- **JavaScript (ES6):** DOM manipulation, unit parsing, and conversion formulas
- **Deployment:** GitHub Pages
